# Smart To-Do List

A smart task management web project built using HTML, CSS, and JavaScript. The application helps users organize daily activities by creating tasks, setting reminder times, tracking completed work, and receiving browser notifications.

## Features

* Add and manage tasks
* Set reminder times for tasks
* Browser notification reminders
* Mark tasks as completed
* Delete tasks
* Automatic overdue task highlighting
* Task statistics counter
* Persistent storage using Local Storage
* Clean and responsive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Browser Notifications API
* Local Storage API

## How It Works

1. Enter a task name.
2. Optionally set a reminder time.
3. Click **Add** to save the task.
4. Enable browser notifications to receive reminders.
5. Mark tasks as completed when finished.
6. Delete tasks that are no longer needed.

Tasks are automatically saved in the browser using Local Storage, so they remain available even after refreshing or reopening the page.

## Project Structure

* `index.html` – Structure of the application
* `style.css` – User interface styling
* `script.js` – Task management, reminders, notifications, and storage logic
